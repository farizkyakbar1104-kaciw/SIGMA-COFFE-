# Sigma Coffe Store

Website statis HTML, CSS, dan JavaScript tanpa halaman Admin.

## Menjalankan lokal
Buka `index.html` di browser. Pastikan folder `image/` tetap berada di sebelah file `index.html`.

## Upload ke GitHub Pages
1. Buat repository GitHub baru.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, dan folder `image/` beserta seluruh PNG di dalamnya.
3. Buka Settings → Pages.
4. Pada Build and deployment, pilih Deploy from a branch, branch `main`, folder `/(root)`, lalu Save.
5. Tunggu publikasi selesai dan buka URL GitHub Pages.

Catatan: ganti nomor WhatsApp contoh di `script.js` dan tautan WhatsApp di `index.html` dengan nomor toko yang benar.
